CSS Specificity number scoring system
that helps more than one style rule focus on same element
which specific style rule will be applied on the element based on the specificity value with !important

  • Inline CSS - 1, 0, 0, 0
  • Id - 0, 1, 0, 0
  • class, pseudo class, attrubute - 0, 0, 1, 0
  • element, pseudo element - 0, 0, 0, 1
  • * universal - 0, 0, 0, 0
