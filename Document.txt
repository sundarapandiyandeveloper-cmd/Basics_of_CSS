CSS Syntax: 
----------- 
	A CSS rule consists of a selector and a declaration block
	
	Selector 
	{							
		color: blue; 		/* Declaration statement 1 (color - property, blue - value) */
		font-size: 12px; 	/* Declaration statement 2 */
	} 
	
Example: 
-------- 
	p 
	{
		color: blue; 
		font-size: 12px; 
	} 
	
Selector Types: 
--------------- 
	1. Simple selectors (select elements based on name, id, class) 
	2. Combinator selectors (select elements based on a specific relationship between them)
	3. Pseudo-class selectors (select elements based on a certain state)
	4. Pseudo-elements selectors (select and style a part of an element)
	5. Attribute selectors (select elements based on an attribute or attribute value) 

1. Simple Selector: 
------------------- 
	Universal Selector (*) - Selects all elements 
	Element Selector (element_name) - Selects all <p> elements 
	Class Selector (.class_name) - Selects all elements with match the class name 
	Specific Class Elements Selector(element_name.class_name). 
	Grouping Selector - Select all element1, element2, .., elementN. 
	
2. Combinator selector: 
----------------------- 
		select elements based on a specific relationship between them. 
		A combinator is a sign that(' ', '>', '+', '~', ',', '|') explains the relationship between selectors. 
		
		Types: 
		------
			1. Descendant Combinator (' ') -  selects all elements that are descendants (children, grandchildren, etc.) of a specified element.
			2. Child Combinator ('>') - selects all elements that are direct children of a specified element.
			3. next Sibling Combinator ('+') - select an element that is directly after a specific element. Sibling elements must have the same parent element.
			4. Subsequent-sibling combinator ('~') - selects all elements that are next siblings of a specified element. and share the same parent. 
			5. Selector-list Combinator (',') - select all the matching elements. Separate each element name with a comma.

Pseudo Class Selector: 
----------------------
	pseudo-class is a keyword that can be added to a selector, to define a style for a special state of an element. 

Some common use for pseudo-classes:
----------------------------------- 
	Style an element when a user moves the mouse over it
	Style visited and unvisited links differently
	Style an element when it gets focus
	Style valid/invalid/required/optional form elements
	Style an element that is the first child of its parent

Syntax: 
------- 
	Pseudo-classes are always denoted by a single colon (:) followed by the pseudo-class name 

	selector:pseudo-class-name 
	{
		CSS properties
	} 

CSS Position: 
	position - ([default]static, relative, absolute, fixed). 

1. position: static (default)
	Every element is static unless you change it.
	The element follows normal document flow.
	Top/left/right/bottom have no effect. 

2. position: relative
	Still stays in normal document flow.
	BUT you can move it relative to its original position using top / left / right / bottom.
	It also becomes the positioning reference for absolutely positioned children.

3. position: absolute
	Removed from the normal flow.
	Positioned relative to the first ancestor that has position: relative, absolute, or fixed.
	If none exist, it positions relative to the viewport.

4. position: fixed
	Stays fixed to the viewport, even during scroll.
	Removed from normal flow.
	Always stays at the same place on the screen. 

| Position     | In Flow? | Moves With Scroll? | Positioned Relative To      |
| ------------ | -------- | ------------------ | --------------------------- |
|   static     | ✔ yes    | ✔ yes             | normal flow                 |
|   relative   | ✔ yes    | ✔ yes             | its original position       |
|   absolute   | ❌ no    | ✔ yes             | nearest positioned ancestor |
|   fixed      | ❌ no    | ❌ no             | viewport                    |

Outline in CSS: 
--------------- 
	outline-style - Set the style of an outline 
	outline-width - Set the width of an outline 
	outline-color - Set the color of an outline 
	outline - A shorthand property for setting outline-width, outline-style, and outline-color in one declaration 
	outline-offset - Specifies the space between an outline and the edge or border of an element 

Text Formatting 
--------------- 
	vertical-align 
	--------------
		used to control the vertical positioning of an inline or inline-block element relative to its line box or 
		table-cell container. It does not work on block-level elements by default. 

Text Shadow 
----------- 
	text-shadow 
	----------- 
		adds shadow to text. In its simplest use, you only specify the horizontal and the vertical shadow. 
		In addition, you can add a shadow color and blur effect. 

		The text-shadow property also accepts multiple shadows for an element. Define each shadow in a comma-separated list.
		Example: text-shadow: 0 0 3px #ff0000, 0 0 5px #0000ff; 

font-weight: 
------------ 
	normal - This is default. Defines normal characters
	bold - Defines thick characters
	bolder - Defines thicker characters
	lighter - Defines lighter characters
	100-900 - Defines from thin to thick characters. 400 is the same as normal, and 700 is the same as bold
