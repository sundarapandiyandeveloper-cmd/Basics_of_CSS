CSS Syntax: 
----------- 
	A CSS rule consists of a selector and a declaration block
	
	Selector 
	{							
		color: blue; 		/* Declaration statement 1 (color - property, blue - value) */
		font-size: 12px; 	/* Declaration statement 2 */
	} 
	
Example: 
-------- 
	p 
	{
		color: blue; 
		font-size: 12px; 
	} 
	
Selector Types: 
--------------- 
	1. Simple selectors (select elements based on name, id, class) 
	2. Combinator selectors (select elements based on a specific relationship between them)
	3. Pseudo-class selectors (select elements based on a certain state)
	4. Pseudo-elements selectors (select and style a part of an element)
	5. Attribute selectors (select elements based on an attribute or attribute value) 

1. Simple Selector: 
------------------- 
	Universal Selector (*) - Selects all elements 
	Element Selector (element_name) - Selects all <p> elements 
	Class Selector (.class_name) - Selects all elements with match the class name 
	Specific Class Elements Selector(element_name.class_name). 
	Grouping Selector - Select all element1, element2, .., elementN. 
	
2. Combinator selector: 
----------------------- 
		select elements based on a specific relationship between them. 
		A combinator is a sign that(' ', '>', '+', '~', ',', '|') explains the relationship between selectors. 
		
		Types: 
		------
			1. Descendant Combinator (' ') -  selects all elements that are descendants (children, grandchildren, etc.) of a specified element.
			2. Child Combinator ('>') - selects all elements that are direct children of a specified element.
			3. next Sibling Combinator ('+') - select an element that is directly after a specific element. Sibling elements must have the same parent element.
			4. Subsequent-sibling combinator ('~') - selects all elements that are next siblings of a specified element. and share the same parent. 
			5. Selector-list Combinator (',') - select all the matching elements. Separate each element name with a comma.

Pseudo Class Selector: 
----------------------
	pseudo-class is a keyword that can be added to a selector, to define a style for a special state of an element. 

Some common use for pseudo-classes:
----------------------------------- 
	Style an element when a user moves the mouse over it
	Style visited and unvisited links differently
	Style an element when it gets focus
	Style valid/invalid/required/optional form elements
	Style an element that is the first child of its parent

Syntax: 
------- 
	Pseudo-classes are always denoted by a single colon (:) followed by the pseudo-class name 

	selector:pseudo-class-name 
	{
		CSS properties
	} 

CSS Position: 
	position - ([default]static, relative, absolute, fixed). 

1. position: static (default)
	Every element is static unless you change it.
	The element follows normal document flow.
	Top/left/right/bottom have no effect. 

2. position: relative
	Still stays in normal document flow.
	BUT you can move it relative to its original position using top / left / right / bottom.
	It also becomes the positioning reference for absolutely positioned children.

3. position: absolute
	Removed from the normal flow.
	Positioned relative to the first ancestor that has position: relative, absolute, or fixed.
	If none exist, it positions relative to the viewport.

4. position: fixed
	Stays fixed to the viewport, even during scroll.
	Removed from normal flow.
	Always stays at the same place on the screen. 

| Position     | In Flow? | Moves With Scroll? | Positioned Relative To      |
| ------------ | -------- | ------------------ | --------------------------- |
|   static     | ✔ yes    | ✔ yes             | normal flow                 |
|   relative   | ✔ yes    | ✔ yes             | its original position       |
|   absolute   | ❌ no    | ✔ yes             | nearest positioned ancestor |
|   fixed      | ❌ no    | ❌ no             | viewport                    |

Icons
----- 
	Icons can easily be added to your HTML page, by using an icon library.

How To Add Icons 
---------------- 
	The simplest way to add an icon to your HTML page, is with an icon library, such as CSS Bootstrap library. 
	Add the name of the specified icon class to any inline HTML element (like <i> or <span>). 
	Icons can be customized with CSS (size, color, shadow, etc.) 

Bootstrap Icons
--------------- 
	To use the Bootstrap glyphicons, add the following line inside the <head> section of your HTML page 
	<link rel="stylesheet" href="https://maxcdn.bootstrapcdn.com/bootstrap/3.3.7/css/bootstrap.min.css"> 

	Example: 
	-------- 
		<i class="glyphicon glyphicon-cloud"></i>
		<i class="glyphicon glyphicon-remove"></i>

CSS list
-------- 
	list-style-type - Specifies the type of list-item marker (ul[{default value}disc, circle, square, none] - ol[{default value}decimal, lower-alpha, upper-alpha, lower-roman, upper-roman]) 
	list-style-image - Specifies an image as the list-item marker
	list-style-position - Specifies the position of the list-item markers
	list-style - A shorthand property for the properties above 

CSS Table 
--------- 
	border-collapse - used in table element.possible values are (default value)separate, collapse.  
	border-spacing - sets the distance between the borders of adjacent cells. Note: This property works only when border-collapse is set to "separate".
	vertical-align - sets the vertical alignment (like top, bottom, or middle) of the content in <th> or <td>. Note: By default, the vertical alignment of the content in a table is middle (for both <th> and <td> elements). 

Width - Properties 
------------------ 

width 
----- 
	Sets the actual width of an element.
	Can be a fixed value (200px), percentage (50%), or auto. 

	Example: 
		div 
		{
			width: 300px;
		}

	The element will be exactly 300px wide, unless min-width or max-width override it. 

max-width 
--------- 
	Sets the largest width an element is allowed to grow to.
	Even if the parent container is very wide, the element will not exceed this value. 

	Example: 
	div 
	{
		max-width: 500px;
	}

	The element will never be wider than 500px. 

min-width 
--------- 
	Sets the smallest width an element is allowed to shrink to. 
	Even if content is small or the screen is narrow, the width cannot go below this value. 

	Example: 
	div 
	{
		min-width: 200px;
	} 

	The element will never be smaller than 200px, even if width is smaller.

float
----- 
	specifies how an element should float within its container. 
	It places an element on the left or right side of its container, allowing text and inline elements to wrap around it. 
	It is used for positioning and formatting content e.g. let an image float left to the text in a container. 
	It is often used to wrap text around images! 

	Possible Values: 
	---------------- 
		left - The element floats to the left of its container 
		right - The element floats to the right of its container 
		none - Default. The element does not float and is displayed just where it occurs in the text 
		inherit - The element inherits the float value of its parent 

clear 
----- 
	The clear property specifies what should happen with the element that is NEXT to a floating element.
	The clear property prevents elements from wrapping around or beside the floated content. 

	Possible Values: 
	---------------- 
		none - Default. Allows elements to float on either side
		left - The element is pushed below floated elements on its left side
		right - The element is pushed below floated elements, on its right side
		both - The element is pushed below floated elements, on both its left and right side
		inherit - The element inherits the clear value from its parent 

CSS Pseudo Elements

Some common use for pseudo-elements

::after 
------- 
	 Used to insert some content after the content of a specified element.

Dialog Box 
---------- 
	A dialog box is a small window that appears on top of a webpage (or application) 
	to communicate something to the user or ask for input. 
	It usually pauses the main content until the user interacts with it.

	In web development, dialog boxes are often used for:
	---------------------------------------------------- 
		Confirmations (e.g., “Are you sure you want to delete?”)
		Forms (login, signup, feedback)
		Alerts or messages
		Custom pop-up interfaces 

In simple words
--------------- 
	A dialog box = a pop-up window used to interact with the user.

HTML Dialog Box
--------------- 
	In HTML, a dialog box is typically created using the <dialog> element.

	Example: 
	-------- 
		<dialog id="box">
			<p>This is a dialog box!</p>
			<button onclick="box.close()">Close</button>
		</dialog>

		<button onclick="box.showModal()">Open Dialog</button>
Types: 
	Modal = “Stop everything and deal with me first.”
	Non-modal = “I’m here, but you can keep doing whatever you want.” 

| Feature                 | Modal Dialog                   | Non-Modal Dialog      |
| ----------------------- | ------------------------------ | --------------------  |
| Blocks page interaction | ✔ Yes                          | ✖ No                 |
| User must close it      | ✔ Yes                          | ✖ No                 |
| Focus trapping          | ✔ Yes                          | ✖ No                 |
| Use cases               | Confirmations, login, warnings | Tools, notifications  |
| Open method             | showModal()                    | show()                | 

1. Modal Dialog
---------------
	A modal dialog is a dialog window that blocks interaction with the rest of the page until the user closes it. 

Key Characteristics 
------------------- 
	The user cannot click, scroll, or interact with anything outside the dialog.
	Focus (tab navigation) is trapped inside the dialog.
	Ideal when you need the user’s attention for something important. 

How to open a modal dialog
-------------------------- 
	dialog.showModal();

Example of a Modal Dialog
------------------------- 

<dialog id="modalDialog">
	<h3>Important Message</h3>
  	<p>You must confirm this action before proceeding.</p>
  	<button onclick="modalDialog.close()">OK</button>
</dialog>

<button onclick="modalDialog.showModal()">Open Modal Dialog</button>

When to use a Modal Dialog
-------------------------- 
	Delete confirmation
	Login popup
	Critical warnings
	Required form input
	Anything where the user must respond before continuing 

Why modal dialogs are important 
------------------------------- 
	They prevent accidental clicks outside the popup and improve accessibility by keeping keyboard focus inside the dialog.  

2. Non-Modal Dialog
------------------- 
	A non-modal dialog is a popup that does NOT block interaction with the rest of the webpage. 

Key Characteristics
------------------- 
	The user can continue interacting with the page behind the dialog.
	The dialog behaves like a floating window.
	Focus is not trapped—user can click anywhere.

How to open a non-modal dialog 
------------------------------ 
	dialog.show();

Example of a Non-Modal Dialog 
----------------------------- 

<dialog id="nonModalDialog">
  	<h3>Notification</h3>
  	<p>You can still interact with the page behind this dialog.</p>
	<button onclick="nonModalDialog.close()">Close</button>
</dialog>

<button onclick="nonModalDialog.show()">Open Non-Modal Dialog</button>

When to use a Non-Modal Dialog
------------------------------ 
	Chat windows (floating)
	Tool panels (like photo editor side windows)
	Small tips or hints
	Information popups that don’t require user action

@media 
------ 

Meaning of only screen
---------------------- 
	screen = apply styles to screens (desktops, laptops, tablets, phones). 
	only = only = a filter that prevents older browsers from applying the styles. 

Full example:
------------- 
	@media only screen and (max-width: 768px) 
	{
		/* styles */
	}

Why do we use only?
------------------- 
	In modern browsers, using only is optional. 
	It mainly existed to prevent old browsers (IE8 and earlier) from misinterpreting the media query. 


Without only
------------  
	@media screen and (max-width: 768px) { ... }

With only 
--------- 
	@media only screen and (max-width: 768px) { ... }

Functionally, they work the same in all current browsers.

What does screen mean?
---------------------- 
	It tells the browser:
		“Apply these styles to screen-based devices” 
		—not to printers, TVs, projectors, etc. 

Other media types include:
-------------------------- 
	| Media Type | Meaning                   |
	| ---------- | ------------------------- |
	| `screen`   | Phones, tablets, monitors |
	| `print`    | Printed/PDF documents     |
	| `speech`   | Screen readers            |

Summary
------- 
	| Part       | Meaning                                   | Usefulness today   |
	| ---------- | ----------------------------------------- | ------------------ |
	| screen     | Targets display devices                   | Commonly used      |
	|   only     | Prevents old browsers from applying rules | Not required today |

Final Answer: 
------------- 
	only screen means:
		“Apply this media query only on screen devices, and ignore it in old browsers.”

Attribute Selector 
------------------  
	used to select and style HTML elements with a specific attribute or attribute value, or both. 

[attribute]			Select elements with a specific attribute
[attribute=value]	Select elements with a specific attribute with an exact value
[attribute~=value]	Select elements with an attribute value containing a specific word
[attribute|=value]	Select elements with the specific attribute, whose value can be exactly the specific value, or start with the specific value followed by a hyphen (-)
[attribute^=value]	Select elements with the specific attribute, whose value starts with a specific value
[attribute$=value]	Select elements whose attribute value ends with a specific value
[attribute*=value]	Select elements whose attribute value contains a specific value
